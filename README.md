# Time Series Datasets and Models

[INSTALLATION](#installation) | [DOCUMENTATION](#documentation) | [CONTRIBUTING](CONTRIBUTING.md) | `LICENSE`

This repository contains tools to import important time series datasets and baseline models.

## Documentation

The documentation is hosted at <https://bvt-htbd.gitlab-pages.tu-berlin.de/kiwi/tf1/tsdm>. Alternatively, it can be
built with Zensical locally by running `just docs::build` from the repository root.
The HTML output is written to `docs/build/site/`.

## Installation

Install via pip:

```bash
pip install -e .
```
